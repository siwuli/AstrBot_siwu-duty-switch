# 上下班开关（duty_switch）

按群独立的作息开关：某群下班后该群消息全部静默，其它群不受影响。

## 功能

- 在某个群发「上班」「下班」只影响该群，各群状态互相独立；
- 下班后该群消息全部静默：不回复、不触发插件、不调用 LLM；
- 指令需 @ 机器人或唤醒词触发，默认仅群主/管理员可执行；
- 状态按群 ID 持久化，重启 AstrBot 后保持；
- 提示口吻拟人化，机器人自称与对用户称呼可配置。

## 使用

| 指令 | 效果 |
| --- | --- |
| 上班 | 当前群恢复接收与回复，各插件与 LLM 照常运行 |
| 下班 | 当前群消息全部静默拦截，其它群不受影响 |

- 需 @ 机器人或唤醒词触发（如「兔兔下班」）；私聊无法定位目标群，请在群里操作；
- 下班群的管理员仍可发「上班」把该群叫醒。

## 配置

| 配置项 | 默认 | 说明 |
| --- | --- | --- |
| duty_enabled | true | 插件总开关 |
| duty_permission_enabled | true | 指令是否需要管理员权限 |
| duty_admin_ids | 空 | 可执行开关的用户 ID 白名单 |
| duty_admin_role | owner, admin | 群内可执行开关的角色 |
| duty_start_on | true | 未操作过的群的默认状态 |
| duty_persist | true | 持久化开关状态 |
| duty_off_reply | true | 切换后是否回复确认 |
| duty_bot_name | 兔兔 | 机器人自称 |
| duty_user_title | 主人 | 对用户的称呼 |

## 安装

1. 把插件目录放到 AstrBot 的 data/plugins/duty_switch，或上传打包后的 zip；
2. 重启 AstrBot，在群里 @ 机器人 发送「下班」验证。
